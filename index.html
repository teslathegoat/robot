01/Research interests

Two lenses — one instinct

The bug classes I keep coming back to.

01

Web Security

The browser is the largest unpatched asset most companies own. I hunt the bugs living between rendering and trust — sanitizer confusion, desync, and the request tricks that turn an "informational" finding into full account takeover.

  • DOM-based XSS & client-side taint chains
  • Request smuggling & desync at the edge
  • SSRF, cloud metadata & egress abuse
  • Clickjacking, CSRF & business-logic flaws
02

Application Security

Code review with an attacker's muscle memory. I trace untrusted input from source to sink across services, then build the gates, tests and threat models that keep the same bug class from regressing next quarter.

  • OAuth, OIDC & JWT threat modeling
  • Coverage-guided fuzzing of parsers
  • Supply-chain & CI/CD hardening
  • Threat models engineers actually read

03/Vulnerability research

All issues coordinated & patched

Full disclosure, done right.

CVE-2024-31337

Stored XSS via SVG sanitizer namespace confusion

MailForge Webmail — client-side sanitizer

 CRITICAL 9.12024.06

The sanitizer whitelisted <svg> tags but re-parsed sanitized output in a lenient XML mode, letting an xlink:href namespaced payload survive sanitization and execute inside the mailbox view. A single self-delivering email compromised sessions account-wide.

DisclosureReported 04.18→Triaged 04.20→Patched 05.21→Public 06.12 · 2024
CreditElias RehnClassStored XSS
CVE-2023-49220

SSRF in multi-tenant webhooks via redirect chain

RelayHook — outbound delivery service

 HIGH 8.22023.11

Webhook delivery followed redirects into link-local space after DNS re-resolution. Chaining a 302 to the cloud metadata service aliased instance credentials into outbound delivery headers. Fixed with pin-and-verify egress plus metadata hop limits.

DisclosureReported 09.02→Triaged 09.04→Patched 10.19→Public 11.07 · 2023
CreditElias RehnClassSSRF
CVE-2023-41882

JWT algorithm confusion in a fintech SDK

Ledgr SDK — token verification library

 HIGH 7.42023.08

The verifier accepted HS256 tokens when an RSA public key was configured, using the PEM body as the HMAC secret. Crafted tokens passed verification in default deployments. Patched by pinning the algorithm allowlist to the configured key type.

DisclosureReported 06.11→Triaged 06.13→Patched 07.22→Public 08.15 · 2023
CreditElias RehnClassAuth bypass — JWT
CVE-2022-30517

Session fixation via subdomain cookie injection

Deskline Helpdesk — session management

 MEDIUM 5.32022.04

A permissive Domain attribute shared across subdomains allowed cookie injection from a co-tenant host, enabling silent session fixation for support agents. Fixed by scoping cookies to the application origin and rotating identifiers on every auth event.

DisclosureReported 03.02→Triaged 03.03→Patched 04.11→Public 04.28 · 2022
CreditElias RehnClassSession fixation
