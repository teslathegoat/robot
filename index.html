CVE-2024-38192 CRITICAL

Authentication Bypass in Enterprise SAML Gateways

A signature-wrapping flaw in four widely deployed SAML service-provider libraries allowed full account takeover with a single crafted assertion — no credentials, no interaction.

2024 · 14 MIN
The long version

Four SAML libraries parsed the assertion referenced by the signature, but enforced trust based on the response envelope. By rewriting the Reference URI to point at an attacker-supplied assertion while keeping the original <Signature> block, validation passed on XML that was never actually signed. The result was a one-request account takeover on every affected deployment I tested — including two Fortune-500 SSO gateways.

002
CVE-2023-44790 HIGH

Stored XSS via PDF Polyglots in Document Pipelines

Chaining MIME confusion with an unsafe PDF-to-HTML converter to execute script in the origin of every user who previews a shared file.

2023 · 11 MIN
The long version

The preview service sniffed the multipart body before the MIME allowlist ran, so a file that parsed as both valid PDF and valid HTML crossed the boundary as a PDF and landed as HTML. The converter preserved embedded <JS> objects into script tags. Anyone who previewed a shared document executed attacker script in the application origin — a stored XSS with nothing but file-upload reach.

CVE-2023-27321 CRITICAL

From SSRF to RCE: Abusing Cloud Metadata Endpoints

A blind SSRF in a webhook validator, pivoted through IMDSv1 into long-lived credential theft and a full production-environment compromise.

2023 · 18 MIN
The long version

A webhook validator fetched attacker-supplied URLs from an internal network position, but its blocklist only covered public CIDR ranges. DNS rebinding got me past the re-resolution check; IMDSv1 did the rest. Within an hour I held a deploy role with write access to production artifacts — the full chain is documented together with the fixes and detections the vendor shipped.

004
GHSA-7f2c-q9x4-m3pj MEDIUM

ReDoS in Regex-Based WAF Rule Engines

Catastrophic backtracking in commonly shipped rule chains — how 40kb of crafted query string bypassed a WAF and pinned its workers at 100% CPU.

2022 · 9 MIN
The long version

The default rule set shipped a chain whose lookahead regex hit catastrophic backtracking on roughly 40kb of crafted query string. One request pinned a worker core; eight killed the connection pool. The vendor added linear-time guards in 3.2, and the research produced a reusable fuzzer for regex-based rule engines that has since found three more instances in unrelated projects.
