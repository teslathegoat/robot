Profile

The strongest defense is a published, reproducible offense.

For nine years I've sat on both sides of the breach — first as a backend engineer at Kestrel Systems, where one production incident I still think about turned me toward offense; independent since 2021, breaking the things other people build. Every finding ends up public: a write-up, a tool, a talk. Disclosure done properly is the only control that reliably raises the bar.

My research lives in the gap between what an application claims to validate and what it actually does. That gap has produced twenty-three CVEs, two Pwn2Own entries, and tooling used daily by roughly forty thousand practitioners. I report responsibly, always — Meridian Bank got their exploit before their customers' data hit a forum.

ADV-2024-013 CRIT 9.8 Unauthenticated RCE in the Trident CMS template engine CVE-2024-38812 · Sandbox escape → deserialization → code exec · 2024-09-02 · 14 min

Trident's theme editor exposes a Twig-derived template engine behind a sandbox that, per vendor documentation, "cannot reach internal objects." By assembling an object graph across three individually harmless template functions, the sandbox's security check is skipped entirely, landing in a gadget that hands attacker-controlled data to unserialize() — no authentication required. A single POST request yields code execution.

ADV-2024-009 HIGH 8.6 From PDF export to cloud metadata in Helix Docs CVE-2024-31007 · Renderer → gopher → IMDSv2 bypass · 2024-05-14 · 11 min

Helix Docs converts shared documents to PDF through a headless renderer. HTML injection in the export flow was known and rated low — until the renderer's network layer turned out to accept gopher://, allowing raw HTTP to be hand-crafted without a client library. Chained against IMDSv2, the token PUT requirement can be satisfied within the same request stream, yielding the instance role credentials in full.

ADV-2023-017 HIGH 8.1 JWT audience confusion in Kestrel SSO — one token, every tenant CVE-2023-42698 · AUD claim unvalidated → cross-tenant impersonation · 2023-11-20 · 9 min

Kestrel's SSO verifies signature and expiry but treats the aud claim as advisory. A token minted for a low-trust marketing tenant, replayed against the admin console callback with a tweaked path, validates cleanly — and every downstream identity is derived from the token's sub. One self-registered account became a skeleton key for the entire fleet.

ADV-2023-011 MED 6.5 Web cache deception at the CDN edge — cross-tenant PII leakage CVE-2023-35707 · Path confusion → cacheable 200 → PII oracle · 2023-06-08 · 12 min

A CDN routing rule treats /account and /account.js as equivalent; the origin does not. Appending a static extension to authenticated endpoints caused the CDN to cache personalized responses under public keys. Six weeks of passive measurement confirmed repeatable leakage of account data across tenants. The vendor declined the first report; a delegated, self-terminating proof changed their mind.

ADV-2022-006 CRIT 9.1 Dependency confusion to production — internal registry takeover CVE-2022-29455 · Namespace squat → postinstall hook → build runner · 2022-03-17 · 16 min

Three internal packages at a Fortune 100 were resolvable by name from the public registry — no scope prefix, no allowlist. I registered placeholders with a benign postinstall script that proved, conclusively, it executed inside CI build runners holding deploy secrets. The script printed its environment to build logs and nothing left the pipe. Coordinated fix took eleven hours; the class of bug took the industry a year.
