About Me

I am a cybersecurity enthusiast with a strong interest in web application security, software security, and vulnerability research. My work focuses on identifying and understanding security weaknesses in modern web applications, analyzing attack surfaces, and exploring effective approaches to improving application security.

I am particularly interested in web security research, secure software development, authentication and authorization mechanisms, and automated vulnerability discovery. I enjoy exploring security challenges through practical experimentation and continuous learning.

I aspire to contribute to academic research in cybersecurity, particularly in areas involving software security, web application protection, and automated security analysis. I am currently interested in pursuing graduate research opportunities in these areas.
